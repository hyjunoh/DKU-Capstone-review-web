# Layer 4 — 유용성 (선호 비교)  ⬜ 미정 / 향후

§3 4층 구조의 최상층. 앞 3층이 "틀리지 않음(안전·안정·정합)"을 증명한다면, 4층은
**"실제로 더 유용한 요약인가"**를 선호 비교로 본다.

## 방향 (초안 — 확정 전)
- **쌍 선호 비교(pairwise preference)**: 같은 게임에 대해 파이프라인 요약 vs 대조군 요약을
  블라인드(A/B 무작위 배치)로 제시하고, 어느 쪽이 구매 판단에 더 유용한지 판정.
  - 판정자 후보: 독립 LLM(Gemini) 판정 / 사람 평가 / 둘 다.
  - 평가 기준 예: 근거 충실(무근거 주장 없음)·스포일러 안전·장단점 균형·구체성·구매 유용성.
- 통계: 승률 + 부호검정/Wilcoxon, 위치 편향 통제(A/B 무작위).

## 주의 (앞선 관찰 반영)
- 파이프라인 최종 텍스트엔 redaction 아티팩트("후반부 핵심 요소")·모호한 메타 표현이 있어,
  단순 "가독성" 판정은 대조군에 유리할 수 있다(폐지된 ablation·Layer 1 관찰). 선호 기준을
  "근거·정확·유용성" 중심으로 설계하고, 양날 결과도 정직 보고.
- 메트릭을 입맛대로 더 찾는 식의 p-hacking 금지. 기준·판정 프롬프트를 결과 전에 고정.

## 상태
- 미착수. 구체 설계는 Layer 3 완료 후 확정.
